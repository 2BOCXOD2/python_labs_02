# Описание реализованной иерархии классов

### В качестве базового класса был использован класс Transport из лабораторной работы №1. Он содержит общие для всех видов транспорта атрибуты: name (имя), vmestimost (вместимость) и sr_skorost (средняя скорость).

### На его основе были созданы два дочерних класса:

### CargoShip (Грузовой корабль): добавляет атрибуты cargo_capacity_tons (грузоподъёмность) и route_length_nm (длина маршрута).
### Airplane (Самолёт): добавляет атрибуты max_flight_altitude_m (максимальная высота полёта) и fuel_consumption_lph (расход топлива).
### Различия между классами проявляются в реализации бизнес-логики. Каждый дочерний класс переопределяет методы для расчёта своей стоимости (calculate_price) и описания (__str__), что позволяет им вести себя по-разному при вызове одинаковых методов.

Наследование (class CargoShip(Transport)): класс CargoShip — это разновидность класса Transport. Он автоматически получает все его атрибуты (name, vmestimost, sr_skorost) и методы (opisanie, activate).
super().__init__(): это ключевая команда. Вместо того чтобы копировать код self._name = name и валидацию из ЛР-1, мы просто перекладываем работу по инициализации общих свойств на класс Transport.
Новые атрибуты: мы добавили то, что специфично только для кораблей или самолетов (грузоподъемность, высота полета).
Новый метод: мы добавили логику, которая имеет смысл только для конкретного вида транспорта (расчет времени рейса или дальности полета).
Отсутствие дублирования: код класса Transport живет только в одном месте (src/lab01/models.py). Если мы захотим изменить логику валидации имен, нам нужно будет сделать это только там. Все дочерние классы (CargoShip, Airplane) автоматически подхватят изменения.
